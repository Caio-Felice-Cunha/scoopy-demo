Architecture

Progressive enhancement keeps the story optional.

Synthetic catalog→Product UI→Deterministic scoop→Browser-only resultCapability gate→Three.js scene→GSAP scroll chapters→Static fallback

Why static?

The demo needs no account, backend, database, analytics, or paid service. GitHub Pages is the full runtime.

Why deterministic?

A stable hash makes the interaction testable and lets a recruiter reproduce the same state.

Why a fallback?

Content remains readable when WebGL, motion, or JavaScript capabilities are limited.

Workflow

From approved visual prototype to public evidence.

Annotated public code

Small functions carry the important guarantees.

Deterministic selectioncatalog.mjs ↗
export function deterministicScoop(items, size, seed) {
  const count = Math.max(0, Math.min(Number(size) || 0, items.length));
  return seededOrder(items, seed).slice(0, count);
}

The seed is derived from theme and tier, so tests and visitors can reproduce a scoop.

Capability gateindex.html ↗
var mode = 'none';
var canvas = document.createElement('canvas');
if (canvas.getContext('webgl2') || canvas.getContext('webgl')) {
  mode = 'auto';
}
window.__scoopMode = mode;

The content path is the default; the 3D layer earns permission from browser capabilities.
